## 2. 关键实验证据（HistGB，混合跑）

| 方法 | 特征 | 验证方式 | R² |
| --- | --- | --- | --- |
| A. 用户基线 | **CAN 全量**（含电流/功率/温度） | shuffle 5折 | **0.708** |
| B. 单车 | CAN 全量 | shuffle | 车2=0.73 > 车1=0.36 |
| C. 仅运动学 | v,a,v²,v³,v·a 等 | shuffle | 0.42 |
| D. 运动学+海拔+坡度 | + DEM 回填 | shuffle | 0.49 |
| E. 同 D | 同上 | **按行程分组**（预测全新行程） | **0.16** |
| F. **5km 段级聚合** | 段均速/均\|a\|/坡度/海拔/v³/v·a | **按行程分组** | **0.49** |
| G. **段级+历史天气** | F + 温度/风速/湿度（ERA5 回填） | **按行程分组** | **0.54** |
| H. **段级+工况深度特征** | F + 速度分位数/能量积分(e_acc·e_aero·e_grade_up)/启停占比 | **按行程分组** | **0.66** |
| I. **严格"新线路可获取"** | 仅 段均速/坡度/海拔/温度/道路等级/hour | **按行程分组** | **0.31** |
| J. **工况合成（模板拼接）** | I + 合成深度特征（v/a 片段库按 等级×均速 桶拼接） | **按行程分组** | **0.45** |

**三个决定性结论**：

1. **高分是"假象"**：A 的 0.71 主要来自燃料电池电流（\|r\|=0.83）、DC 电流、空压机电流、电堆温度等"准目标"特征——它们与氢耗几乎同源。**新线路上这些特征根本拿不到**（是车辆运行内部状态，无法从路线/环境预测）。
2. **shuffle CV 严重高估**：同组特征，shuffle=0.49 → 按行程分组=0.16。相邻 60s 点高度相关，泄漏让 R² 虚高。**"预测新线路"必须用按行程分组评估**。
3. **段级聚合是可行路线**：60s 点 → 5km 段（1092 段），预测"段均氢耗 g/km"，按行程分组 R²=0.49（RMSE≈2.8 g/km）。段特征更稳、噪声小，且天然契合产品（新线路本来就是按段预测）。
4. **工况深度特征是氢耗核心驱动，也是最大的提升来源**：速度分位数(v_p85)/巡航占比/停车占比/加速·空阻·上坡能量积分(e_acc/e_aero/e_grade_up)把段级 R² 从 0.54 提到 **0.66**。
5. **"新线路可获取特征"（均速/坡度/温度/等级）只有 R²=0.31——差距 0.35 全部来自工况细节**。结论：**工况合成（从道路等级/限速/路况合成秒级 v-t 曲线 → 算深度特征）是必须的中间环节**，这也正是"预测中间变量"的正确落点（预测速度工况，而非电流/功率）。
6. **工况合成可行性已验证（模板拼接法）**：按"等级×均速"8 桶建实车 60s 片段库，v 与 a 分别随机拼接 + 均速对齐 + 坡度调制，合成深度特征喂模型 → **R² 0.31 → 0.45**。合成准确度：e_acc r=0.88、e_aero r=0.89、v_p85 r=0.85；瓶颈：absa_mean/cruise_ratio 段间差异被桶内平均化丢失（r≈0）。
7. **下一步优化方向**：① 更细模板（连续均速分箱 + 坡度分桶）；② a 分布采样（保留段间差异）；③ 坡度调制系数/启停参数用实车校准；④ 消除模板泄漏（按行程分组时片段库只用训练折）。目标 R² 0.45 → 0.55+。

## 3. 对"你的方案"的诊断

你的设想：**输入起终点 → 实地数据 → 预测"表中的部分变量" → 再预测氢耗**。

问题：
- 表中 80 列里，能"从路线/环境预测"的只有少数：车速、纵向加速度、温度类、档位（且都要靠工况合成/估计）；**电流、功率、SOC、压力、氢剩余量等大头不可预测**（取决于驾驶、载重、能量管理策略）。
- 即使能预测车速/加速度，秒级模型在真实泛化（E）只有 R²=0.16。
- 因此"预测 CAN 特征→氢耗"这条两级链路在部署时不可行。

## 4. 推荐方案：段级 + 可获取特征（Data-Driven Segment Model）

```
新线路（起终点）
   ↓ 高德路线 + 分段（已有管线：距离/均速/坡度/海拔/温度/风速/湿度/降水/路况/道路等级/地形/启停）
   ↓ 段级特征（对齐实车段特征：段均速、段均|a|、坡度均值、海拔、v³、v·a、温度、道路等级、路况、hour）
   ↓ 段级氢耗模型（HistGB/GBR，混合跑 + 车辆ID）
   → 每段氢耗 g/km × 段里程 = 线路总氢耗
```

- **训练数据**：实车 60s → 5km 段聚合（F 已验证 R²=0.49）
- **关键待补特征**（提升空间最大，按优先级）：
  1. **历史温度**：✅ 已用 Open-Meteo ERA5 补齐（免费无 key）
  2. **道路等级/路况**（OSM/高德，静态可补）
  3. **载重**（数据里没有；若有载重列则 R² 会大幅提升——氢耗对质量最敏感）
- **工况合成（已验证可行）**：新线路段均速/道路等级/路况 → 模板拼接合成 60s v/a 序列 → 算 v_p85/cruise_ratio/e_acc/e_aero/e_grade_up 等深度特征（实测 R² 0.31→0.45，上限 0.66）；实车 60s 数据即工况片段库（按 道路等级×均速 8 桶）
- **物理校准**：物理需求功率模型（纵向动力学 v,a,grade→功率→氢耗）作为主链 + GBR 学残差，可解释性加分、答辩可讲
