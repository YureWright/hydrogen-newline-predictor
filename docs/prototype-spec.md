# 产品原型设计规格（Figma 用）

> 项目：T05 新线路氢耗预测工具（命题二）
> 用途：在 Figma 中按本规格搭建可交互原型，后续据此实现 React UI

## 设计基调

- 主色：#0b3d2e（深绿）· 辅助色 #1e7a54 / #17a2b8 · 强调橙 #ff8c00（自用站/警示）· 蓝 #1f77b4
- 字体：微软雅黑 / PingFang SC；标题粗体、正文 14-16px
- 风格：卡片式、圆角 12-16px、浅色背景 #f4f7f5、深绿渐变头部

## 页面清单（7 页）

### P0 开始界面（新增）
- 深绿渐变全屏背景 + 氢分子/氢能主题视觉（圆环+原子点缀）
- 标题：**新线路氢耗预测工具**
- 副标题：氢能车辆运营智能分析与决策助手 · T05
- 特性标签：智能路线规划 / 氢耗物理模型 / 柴油对比 / 敏感性分析
- CTA 主按钮：**开始测算** → 跳路线规划
- 底部：版本 + 数据来源说明

### P1 路线规划
- 起终点输入（两个输入框 + 交换按钮；支持地点名或坐标）
- 查询后展示候选路线卡片（最多 3 条）：
  - 里程 / 预计时间 / 过路费 / **高速占比**（进度条）
  - 实时路况摘要（畅通/缓行/拥堵 色点 + 拥堵占比）
  - 沿线加氢站数 + 补能状态徽标（🟢 可行 / 🟡 需绕行补能 / 🔴 不可行）
- 选中一条 → 下一步（车型选择）

### P2 车型选择（含自定义）
- 预设车型卡片（3 款：H49 重卡 / 18t 中卡 / 4.5t 轻卡）：
  - 名称、类别、额定载重、百公里氢耗、柴油对标、储氢/续航
- **自定义车型卡片**（新增）：点击展开表单，字段如下
- 车型可：编辑（克隆为自定义后改）、保存（localStorage 扩展车型库）、删除（仅自定义）

#### 车型参数表单（可扩展架构）
| 分组 | 字段 | 类型 |
| --- | --- | --- |
| 基本信息 | 车型名称、类别（重卡/中卡/轻卡）、品牌 | 文本/下拉 |
| 整车 | 整备质量 kg、额定载重 t、GVW t、风阻系数 Cd、迎风面积 m²、滚动阻力系数 Crr | 数字 |
| 动力能耗 | 百公里氢耗 kg/100km、柴油对标 L/100km、储氢量 kg、续航 km、电堆功率 kW | 数字 |
| 运营成本 | 路桥费率 元/km、维保(氢) 元/km、维保(柴) 元/km | 数字 |
> 设计为**可扩展 schema**：新增字段时仅需在配置表追加，无需改页面结构。

### P3 测算参数
- 载重（吨，滑杆+输入）、趟数、氢价（补贴 30 / 枪口 45 切换）、油价
- 摘要条：已选车型 × 路线（里程/高速占比）

### P4 结果页
- KPI 卡 ×4：单趟氢能总费用 / 单趟柴油对比 / 单趟节省（+%）/ 周期总费用
- 费用构成条形图（燃料/路桥/人工/维保）
- 工况假设明细（合成速度/坡度/温度）
- **补能方案区（如 🟡）**：站点名、绕行里程、加注量、耗时、成本增量
- 柴油 vs 氢能对比条

### P5 敏感性分析
- tornado 图：载重/坡度/高速占比/温度/氢价/油价 ±10% 的影响幅度
- 主影响因子排名

### P6 多方案对比
- 表格：方案 × 车型 × 路线 × 单趟费用 × 周期费用 × 节省（%）
- 排序切换（按费用/节省）、导出 PDF

## 交互流

P0 开始 → P1 路线规划（选线）→ P2 车型选择 → P3 参数 → P4 结果
                                   ↘ P5 敏感性 / P6 多方案（从结果进入）

## Figma 实现要点

- 使用 design tokens（颜色/间距/字号变量），不硬编码
- 组件化：KPI 卡、路线卡、车型卡、输入框、按钮、条形图、tornado、徽标
- 每页一个 Frame（宽度 1440），组件引用共享
