# 可插拔模型 & 评测集协议（v1）

> 让任何"预测模型"和"评测数据"都能按统一格式接入本系统，并用排行榜量化对比。
> 核心就一句话：**模型自己包成 predict.py（stdin/out JSON），评测集是"标准变量 + 真实氢耗"的表格**，系统只负责喂数据、收结果、算误差。

---

## 一、模型导入协议

### 1.1 目录结构（每个模型一个目录）

```
data/models/<模型id>/
├── meta.json     # 报名表（必填）
└── predict.py    # 唯一入口（必填）
```

> 想快速上手？复制模板：`ml/model_templates/baseline_constant/`，改 meta.json 和 predict.py 即可。

### 1.2 meta.json（报名表）

```json
{
  "id": "my_model",            // 必填，全局唯一，与目录名一致
  "name": "我的模型",           // 必填，显示名
  "version": "1.0.0",          // 建议填
  "description": "……",
  "training": { "data": "训练数据说明", "note": "备注" }
}
```

### 1.3 predict.py（唯一入口，格式固定）

从 **stdin** 读，向 **stdout** 写，都是 JSON：

```
输入（stdin）：
{"segments":[
  {"index":0,"distanceKm":10.0,"avgSpeedKmh":80,"gradePercent":0.5,
   "elevationM":1200,"temperatureC":25,"windSpeedKmh":10,
   "humidityPct":40,"roadLevel":"highway","durationH":0.125,
   "massKg":49000,"gainM":10,"stopCount":0,"stopSecondsPer":30, ...}, ...
]}

输出（stdout）：
{"segments":[{"index":0,"h2_kg":0.236}, ...]}   // 每段必须有一个 h2_kg（kg/段）
```

- 模型内部随便怎么算（加载 joblib / PyTorch / ONNX / 纯公式），全部包进 predict.py
- 输出段数必须与输入一致；`h2_kg` 必须是非负有限数
- 模型跑挂了 / 超时 / 输出非法 → 系统标记 error，不影响其他模型

### 1.4 导入与使用命令

```bash
python ml/model_protocol.py list                      # 看所有模型（含内置）
python ml/model_protocol.py smoke <模型id>            # 试工：内置仿真表跑一遍，过了才能用
python ml/model_protocol.py import <模型目录>          # 导入（自动试工，不过就回滚）
python ml/model_protocol.py run <模型id> <input.json> # 对一段数据做预测
```

### 1.5 内置模型（默认基线，天然就是 predict.py 格式）

| id | 名称 | 说明 |
|---|---|---|
| `histgb_ml` | 机器学习 · HistGB（实车+工况合成） | 两辆 H49 实车训练的段级模型 |
| `physics` | 物理模型（能量守恒+启停） | 四阻力+电堆/电池削峰，纯公式白盒 |

## 二、评测集协议

### 2.1 目录结构（每个评测集一个目录）

```
data/evalsets/<评测集id>/
├── meta.json     # {id,name,source,created,n_rows}
└── data.csv      # 每行一条"段"记录：标准变量 + 真实氢耗
```

### 2.2 data.csv 必须列（与模型输入一致，缺一不可）

| 列 | 含义 | 单位 |
|---|---|---|
| `distanceKm` | 段里程 | km |
| `avgSpeedKmh` | 段均速 | km/h |
| `gradePercent` | 坡度 | %（上坡+） |
| `elevationM` | 海拔 | m |
| `temperatureC` | 温度 | ℃ |
| `windSpeedKmh` | 风速 | km/h |
| `humidityPct` | 湿度 | % |
| `roadLevel` | 道路等级 | highway/national/provincial/expressway/city/county/other |
| `durationH` | 段时长 | h |
| `massKg` | 总质量 | kg |
| `h2_kg` | **真实氢耗（ground truth）** | kg/段 |

可选列（有则用、缺省给默认）：`windDirDeg`、`windDirText`、`windAffects`、`gainM`、`stopCount`、`stopSecondsPer`、`vehicle`、`time`。

### 2.3 命令

```bash
python ml/eval_protocol.py list                                # 看所有评测集
python ml/eval_protocol.py create <id> <名称> <data.csv> [来源说明]   # 新建评测集
python ml/eval_protocol.py append <id> <data.csv>              # 往已有评测集追加数据
python ml/eval_protocol.py eval <模型id> <评测集id>             # 单个模型误差
python ml/eval_protocol.py leaderboard <评测集id>              # 全部模型排行榜
python ml/eval_protocol.py download <评测集id>                 # 评测集表格路径
```

### 2.4 排行榜规则

- 每个评测集一张排行榜；**每个模型在每个评测集只有一条成绩**
- 指标：MAE / RMSE / R²（按 RMSE 升序排名）；模型报错则标 ❌ 排在最后
- 内置 HistGB / 物理 / 常量基线自动上榜陪跑——新模型先打败基线才算数

### 2.5 第一个评测集：两车实车评测集

- id：`two_vehicles_real`（5395 行，两辆 H49 实车 60s 行驶窗口）
- 生成脚本：`ml/build_evalset.py`（从 `_v1_feat.csv` / `_v2_feat.csv` 清洗映射）
- 清洗口径（诚实披露）：均速=原始值×0.1；`h2_kg`=每 60s 窗氢耗（质量平衡差分）；`massKg` 默认 30000（无逐窗载重）；`stopCount` 默认 0（无逐窗停车计数）——后续有更细数据可重建
- 当前排行榜（示例）：HistGB 第一（RMSE 0.053 kg），物理与常量基线陪跑

## 三、端到端示例

```bash
# 1) 导入一个模型
python ml/model_protocol.py import my_model_dir

# 2) 新建/追加评测集
python ml/eval_protocol.py create my_eval "我的评测集" my_data.csv "说明"
python ml/eval_protocol.py append my_eval more_data.csv

# 3) 看排行榜
python ml/eval_protocol.py leaderboard my_eval
```
