⚗️ 氢耗物理实验室 · 单路段仿真

物理模型（JS 同源公式） ML 对比（后端） 输入一段路的参数 → 实时算氢耗 + 卡车跑坡动画
📖 说明（老奶奶版 / 数据来源） 这个实验室只模拟一段路：你告诉它"路多长、平均跑多快、坡多大、海拔多高、气温多少、风怎么吹、车多重"，它用与后端 ml/physics.py 完全相同的公式（四阻力 → 轮边功率 → 电堆/电池削峰 → 氢耗）当场算出这段路的氢耗，并把每个中间量都亮给你看。
动画里那辆卡车会按你给的均速在坡上跑：坡度越大路越斜、载重越大车越"压"，改任何一个参数动画和数字一起变。
机器学习对比：需要后端模型（在项目里通过 dev server 打开本页才有）；单独双击打开本文件时仅物理模型可用。

按当前「停车次数 × 单次停车时长」合成的段内速度剖面：加速(0.5 m/s²) → 巡航 → 制动(0.8 m/s²) → 怠速，循环 N 次后最终巡航至终点。与物理模型启停能耗口径一致（每次启停注入动能 ½δmv²，停车期间电堆最低稳定运行）。
