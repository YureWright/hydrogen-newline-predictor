# 燃料电池效率与电堆特性

> 为什么氢耗建模总要"绕着燃料电池效率转"？因为氢气的能量 100% 都得先经过燃料电池变成电，它的效率直接决定"同样的氢气能发多少电"。这篇把它的脾气摸清楚。

---

## 一、燃料电池是"发电机"，不是"电池"

- 普通电池（手机电池）是**存**电的：充进去再放出来。
- 燃料电池是**发**电的：氢气+氧气 实时反应 → 不断出电，只要供氢就一直有电。

反应本质（质子交换膜燃料电池 PEMFC）：

$$\text{阳极（氢）： } H_2 \rightarrow 2H^+ + 2e^-$$
$$\text{阴极（氧）： } \tfrac12 O_2 + 2H^+ + 2e^- \rightarrow H_2O$$
$$\text{总反应： } H_2 + \tfrac12 O_2 \rightarrow H_2O + \text{电} + \text{热}$$

产物只有水和热，所以叫"零排放"。但这"热"就是损耗——能量没有全部变成电。

## 二、效率为什么是"一条山丘曲线"？

燃料电池有个关键特性：**效率不是固定的，而是随着输出功率变化的山丘形曲线**。

```
效率
  │        ╭─────────╮   ← 高效区（大约在 20%~60% 额定功率处）
  │      ╱             ╲
  │    ╱                 ╲
  │  ╱                     ╲
  │╱                         ╲  ← 高功率时效率掉得快（内阻、浓差极化）
  └──────────────────────────────▶ 输出功率
   0      中低功率          额定
```

原因（通俗）：
- **功率太低**：还没开始干活，"维持运转"的辅助消耗（氢泵、空压机、控制器）就占掉很大比例，净效率低。
- **功率太高**：电化学反应"消化不良"，内部电阻损耗、气体扩散不过来（极化损耗）加大，效率骤降。
- **中低功率区间**：辅助损耗占比下降、极化还不严重，出现"最舒服的出力区"。

## 三、为什么这直接影响氢耗建模？

因为在模型里，**燃料电池消耗的氢气 = 燃料电池输出的功率 ÷ 当前效率**：

$$\dot{m}_{H_2,FC}=\frac{P_{FC}(t)}{\eta_{FC}(P_{FC})\cdot LHV_{H_2}}$$

- $LHV_{H_2}$：氢气低热值 ≈ 33.6 kWh/kg
- $\eta_{FC}(P_{FC})$：效率是功率的函数（那条山丘曲线）

**推论**：让燃料电池"在高效区干活"，同样的电耗的氢气就少。所有能量管理策略都在干这件事——见 [[能量管理策略全景]]。

## 四、文献里给出的效率量级

- 现代 PEM 电堆峰值效率约 **50%~60%**；
- 丰田 Mirai 第二代电堆系统效率可到 **~60%**；
- 整条链（电堆+辅机+BOP）实际循环工况下系统效率常见 **40%~50%**；
- 高功率输出时效率可能掉到 **30% 以下**。

> 对照：内燃机热效率一般 30%~40%，燃料电池在中低负荷有优势，高负荷优势缩小——这也是为什么"让电堆轻载跑"是省氢口诀。

## 五、电堆老化的影响

燃料电池用久了：
- 催化剂铂逐渐流失、膜变薄、气体泄漏 → 效率下降；
- 频繁启停、变载、高功率运行加速老化（俗称"把电堆折腾坏"）。

所以很多研究把"氢耗"和"电堆寿命"一起优化（见 [[文献笔记/中文02_朱丹2024_大功率氢燃料电池动力系统节能优化]]、[[文献笔记/英文11_Tang2022_深度强化学习长寿EMS]]、[[文献笔记/中文04_杨继斌2026_融合车速预测与强化学习的能量管理]]）。

## 六、与氢耗模型的接口

拿到一台车的电堆效率曲线（台架实测或厂商数据），把它代入模型，就能：
1. 预测任意工况下的氢耗（Ahn2022、Kang2016）；
2. 找到让氢耗最小的功率分配（所有 EMS 文献）；
3. 评估"换个更高效电堆能省多少"（曾小华2019 的氢耗潜力分析）。
