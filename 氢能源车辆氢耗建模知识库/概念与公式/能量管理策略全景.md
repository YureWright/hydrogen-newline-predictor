# 能量管理策略全景

> 氢耗建模研究里最热闹的战场：**能量管理策略（Energy Management Strategy, EMS）**。它决定"燃料电池和电池谁出力、各出多少"，是省氢的最大杠杆。这篇把它的流派和演进路线讲清楚。

---

## 一、先理解问题：一个"分电"难题

氢车上两个电源（燃料电池 FC + 动力电池 B），行车时每一刻都要决定：

```
      需求功率 P_need(t)
           │
     ┌─────┴──────┐
     ▼            ▼
  燃料电池 FC   动力电池 B
  烧氢气发电    存/放电（可回收）
     │            │
     └────┬───────┘
          ▼
        电机 → 车轮
```

- **电池出得多**：燃料电池轻载，省氢，但电池很快没电。
- **燃料电池出得多**：电池保电，但氢耗高、电堆累。
- **最优解**：根据路况动态分配，让燃料电池尽量待在高效区。

这就是 EMS 要解的优化问题。

## 二、三大流派（由简到繁）

### 1. 规则式（Rule-based）——最朴素，能上车

设定几条"如果……就……"的规则，例如：
- 低功率：电池出力（燃料电池待机）
- 中功率：燃料电池出力（高效区）
- 高功率：燃料电池+电池一起
- 刹车：再生制动回收

**代表**：功率跟随（Power Following）、恒温器、状态机。
**优点**：计算量小、实时性强、真车在用。
**缺点**：不随路况自适应，氢耗不是最优。
**文献**：袁结2022（4种规则策略对比，见 [[文献笔记/中文03_袁结2022_燃料电池客车系统建模与能量管理策略]]）、Zou2023（功率跟随+模糊逻辑，见 [[文献笔记/英文13_Zou2023_功率跟随加模糊逻辑实时EMS]]）。

### 2. 优化式（Optimization-based）——算得更好

用数学优化找"全局或局部最优"：

- **离线全局最优**（已知全程工况，事后算，供对比标杆）：
  - DP 动态规划：把整个工况切成小段递推找最优；
  - 凸优化：把问题写成凸问题高效求解（Long2022 重卡，见 [[文献笔记/英文15_Long2022_凸优化重卡EMS]]）。
- **在线瞬时最优**（实时算一小步）：
  - ECMS 等效氢耗最小：把电池的电折算成"等效氢气"，每步最小化（Zheng2012、Sun2022、林歆悠2024，见 [[文献笔记/英文09_Zheng2012_等效燃料消耗评估]]、[[文献笔记/英文10_Sun2022_ECMS降低氢耗新方法]]、[[文献笔记/中文05_林歆悠2024_里程自适应等效氢耗最小控制]]）；
  - 模型预测控制 MPC：预测未来几秒~几十秒的功率需求再优化（需要工况预测）。

**优点**：更接近最优，氢耗明显更低。
**缺点**：算力需求高，依赖工况预测或模型精度。

### 3. 学习式（Learning-based）——最前沿

用机器学习/强化学习让"分电策略"自己学出来：

- **神经网络预测**：先预测未来车速/功率（BP、LSTM、BiLSTM），再喂给优化器（Topic2022、林歆悠2024、杨继斌2026）；
- **强化学习 RL/DQN/DDPG/SAC**：让智能体试错学习"什么状态该让谁出力"，奖励=省氢+护电池+护电堆（Tang2022、Huang2023、杨继斌2026）；
- **元启发式算法**：秃鹰搜索、粒子群等全局搜最优参数（Savran2024，见 [[文献笔记/英文06_Savran2024_秃鹰搜索优化氢耗]]）。

**优点**：能自适应复杂路况，同时兼顾氢耗+寿命多目标。
**缺点**：训练成本高、可解释性差、部署要算力，多数还在仿真阶段。

## 三、演进路线图

```
规则式（能上车）
   │  加点智能
   ▼
模糊逻辑/功率跟随（实时性最好）
   │  加优化
   ▼
ECMS / MPC（在线优化，依赖预测）
   │  加预测
   ▼
神经网络预测 + ECMS/MPC（林歆悠2024，里程自适应）
   │  加学习
   ▼
强化学习 DRQL/DDPG/SAC（Tang2022/Huang2023/杨继斌2026）
   │  加多目标
   ▼
氢耗 + 电池寿命 + 电堆退化 多目标协同（朱丹2024/杨继斌2026）
```

## 四、降氢耗的"战绩"（文献实测）

| 策略 | 效果 | 文献 |
|---|---|---|
| 秃鹰搜索优化 SOC 边界 | 混动工况氢耗降 57.8% | Savran2024 |
| 模糊协同优化 | 百公里等效氢耗降 8.04%~9.9% | 朱丹2024 |
| SAC-V（车速预测+强化学习） | 等效氢耗降 3.46%、电堆退化率降 3.67% | 杨继斌2026 |
| 4种规则策略最优者 | 6.447 kg/100km | 袁结2022 |

> 注意：不同文献的对比基线、工况不同，数字不能直接横比。但方向一致——**策略优化确实能显著降氢耗**。

## 五、为什么还没有"标准答案"？

1. **真车实时性**：全局最优算法算得慢，装不进车规级控制器；
2. **工况不确定**：未来路况谁知道？预测不准，优化就偏；
3. **多目标冲突**：省氢可能伤电堆/电池，要权衡；
4. **标定与验证成本**：好策略要大量实车/硬件在环验证（肖兴伟2023，见 [[文献笔记/中文06_肖兴伟2023_基于模型的燃料电池物流车能量管理]]）。
