# 行驶阻力与车轮功率

> 所有氢耗模型的"地基"笔记。搞懂这一篇，你就知道"车跑起来到底需要多少能量"是怎么算出来的。

---

## 一、为什么先算"阻力"？

氢耗模型的第一步永远是：**算出车轮需要多大的功率**。因为有了轮边功率，才能反推燃料电池要吐多少电、要烧多少氢（见 [[02_公式手册_氢耗计算的核心公式]]）。

## 二、四种阻力（人话版）

车在路上跑，有四只手在拖后腿：

```
    行驶方向 →
┌─────────────────────────────────────────────┐
│  ① 滚动阻力：轮胎压着地面，摩擦发热          │  车越重、胎越硬、路越糙 → 越大
│  ② 空气阻力：把空气撞开，车头挤开气团        │  速度翻倍 → 变成4倍（v²关系）
│  ③ 坡度阻力：爬坡时地球"往下拽"             │  坡越陡、车越重 → 越大
│  ④ 加速阻力：让静止的车跑起来（牛顿第二定律） │  加速度越大 → 越大
└─────────────────────────────────────────────┘
```

## 三、公式（Ahn & Rakha 2022, Energies 15:529）

$$P_{wheels}(t)=\max\left\{0,\;\left[m a(t)+m g\frac{C_r}{1000}\big(c_1 v(t)+c_2\big)+\frac{1}{2\cdot3.6^2}\rho_{air}A_f C_D v^2(t)+m g\,\theta\right]\cdot\frac{v(t)}{3.6}\right\}$$

逐块拆解：

| 项 | 是什么 | 系数 |
|---|---|---|
| $m a(t)$ | 加速阻力（牛顿第二定律 $F=ma$） | 无 |
| $m g\frac{C_r}{1000}(c_1 v+c_2)$ | 滚动阻力（与速度弱相关） | $C_r=1.75,c_1=0.0328,c_2=4.575$ |
| $\frac{1}{2\cdot3.6^2}\rho_{air}A_f C_D v^2$ | 空气阻力（$\propto v^2$） | $C_D=0.28$（Mirai） |
| $m g\,\theta$ | 坡度阻力 | $\theta$=坡度 |

最后乘以 $\frac{v}{3.6}$：**力 × 速度 = 功率**，把 km/h 换成 m/s 要除 3.6。

## 四、为什么空气阻力是"大头"？

空气阻力跟 $v^2$ 成正比，而功率又再乘一个 $v$，所以**高速时空气阻力在功率里是三次方增长**：速度从 60 提到 120 km/h，仅空气阻力功率就大约变成 8 倍。这就是为什么"跑高速费油/费氢"。

## 五、能量流动视角（曾小华 2019 的方法）

曾小华 2019（[[文献笔记/中文01_曾小华2019_氢耗分析模型与应用]]）用另一种等价思路：追踪能量从"氢气→电→机械→车轮"的流动，定义**平均综合传动效率** $\bar{\eta}$，则：

$$\text{理论氢耗} = \frac{\text{轮边需求能量}}{\bar{\eta}\cdot \text{氢热值}}$$

两者殊途同归：Ahn 是"前向"逐环节求功率，曾小华是"后向"按效率反推。

## 六、一个直觉例子

丰田 Mirai（1928 kg）在平路匀速 90 km/h：
- 滚动阻力功率 ≈ 几十 kW 级别
- 空气阻力功率 ≈ 占大头
- 合计轮边功率约 25~35 kW（经验量级，随参数略变）

再除以传动+电机效率 0.93 → 电源要吐 ~30 kW → 按氢热值折算 → 就得到每小时的氢耗。
