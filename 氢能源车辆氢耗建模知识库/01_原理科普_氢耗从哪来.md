# 01 · 氢耗从哪来？——像给老奶奶讲故事一样

> 这一篇不讲公式，只讲道理。看完这一篇，你会知道氢燃料电池车（FCEV）是怎么"吃"氢气的、氢耗到底受哪些东西影响。所有概念在后面都有对应笔记。

---

## 一、先记住一个大前提：氢燃料电池车其实是一辆"电动车"

很多奶奶会想："氢燃料电池车？是不是像烧煤的火车一样，烧氢气推动车轮？"

**不是的。** 氢燃料电池车本质上是一辆**电动车**——推动车轮的，是一个**电动机**，跟纯电动车（BEV）里的电机一样。

那氢气在哪起作用？**氢气不直接烧，而是"发电"。**

把氢气车想成一个移动的小电厂：

```
氢气（燃料） ──► 燃料电池（像一台安静的小发电机） ──► 电 ──► 电机 ──► 车轮
                        │
                        └── 电也先存进电池（像手机的充电宝）
```

- 氢气和空气中的氧气在燃料电池里"安静地结合"，生成**电 + 水**。水从排气管流出去，干净得能喝。
- 这个"安静地结合"在化学上叫**电化学反应**，不是燃烧。燃烧会冒烟、发热、浪费能量，电化学反应几乎把能量都变成了电。

> 🧓 奶奶版：就像你家的净水器，把水龙头的水"变成"干净水；燃料电池把氢气和氧气"变成"电。净水器不烧水，燃料电池也不烧氢气。

## 二、那"氢耗"是什么？

燃油车说"百公里油耗 8 升"，氢能车就说"百公里氢耗 0.8 公斤"（kg/100km）。

**氢耗 = 车跑 100 公里，一共"喝"掉多少公斤氢气。**

几辆真车的参考值（来自真实文献数据）：
- 丰田 Mirai（轿车）：百公里氢耗约 **0.8~0.98 kg**
- 长城测试车（CLTC-P 工况）：**0.83~0.98 kg/100km**
- 燃料电池公交车（载重更大、走走停停）：**约 6.4 kg/100km**

同样是氢能车，轿车 1 公斤不到，公交要 6 公斤多——差别就在下面要讲的"决定因素"。

## 三、氢耗由什么决定？——一句话版

**氢耗 ≈ 车要克服多少"阻力" ÷ 这一路"能量转换效率"有多高**

车要跑，就得克服四种阻力；克服阻力要花能量；花掉的能量要从氢气里来。氢气"变"成前进的动力，中间要经过好几道转换，每道转换都会"漏"掉一点。

### 决定因素 1：车要克服的四种阻力（这是"要多少能量"）

1. **滚动阻力**——轮胎和地面摩擦。路越粗糙、轮胎越硬、车越重，阻力越大。
2. **空气阻力**——车把空气"挤开"。速度越快，空气阻力越**大得可怕**（跟速度的平方成正比，速度翻倍，阻力变 4 倍）。
3. **坡度阻力**——爬坡要把自己"抬"上去。坡越陡越费劲。
4. **加速阻力**——把车从静止"推"到很快。加速度越大越费劲。

> 🧓 奶奶版：这就像你骑三轮车拉货。路不平（滚动阻力）、刮大风（空气阻力）、上坡（坡度阻力）、突然起步（加速阻力），哪个都会让你多蹬几下（多费力气=多耗氢气）。

### 决定因素 2：整条"能量传送带"的效率（这是"要多少氢气"）

氢气里的能量 → 燃料电池发电 → 电给电机 → 电机带动车轮。每一环都有损耗：

| 环节 | 通俗解释 | 大约效率 |
|---|---|---|
| 燃料电池发电 | 氢气变电，总有一小部分变成热散掉 | 40%~60%（好电堆能到 57%+） |
| 电机驱动 | 电变机械力，也发热 | 90% 左右 |
| 传动系统 | 齿轮轴承摩擦 | 90% 左右 |
| 电池充放电 | 存电取电也有损耗 | 依状态而定 |

**关键**：燃料电池效率不是固定值——它"干活"越重（输出功率越大），效率往往越差；完全闲着或干轻活，效率也差。它有一个"最舒服的出力区间"。这就是后面所有"能量管理策略"要抓住的核心。

### 决定因素 3：整车怎么"分配电"（这是省钱的关键）

氢车上有两个电源：**燃料电池**（烧氢气发电）和**动力电池**（储存回收的电）。

- 起步、加速这种"要大力气"的时刻，电池先顶上（电池反应快）；
- 匀速巡航这种"稳定出力"的时刻，让燃料电池来（它擅长稳定干活）；
- 刹车时，把车轮的动能**回收**成电存进电池（相当于"省下"的氢气）。

谁来指挥"燃料电池出多少、电池出多少"，就是**能量管理策略（EMS）**。策略好不好，直接决定氢耗高不高。有一篇文献用算法优化后，氢耗最高能降 **57.8%**。

> 🧓 奶奶版：燃料电池像个慢性子的老师傅，干重活又慢又费料；电池像个手脚麻利的小徒弟，反应快但力气存得少。聪明的老板（能量管理策略）会分配：重活让小徒弟先上，长路让老师傅慢慢走，刹车时还能把力气"捡回来"存着。老板分配得好，整个店（整车）又省料又出活。

## 四、还有两个"环境变量"不能忽略

1. **路况/工况**：高速巡航、市区走走停停、山路爬坡，氢耗天差地别。所以测氢耗要用**标准工况**（如中国的 CLTC、欧洲的 NEDC/WLTC），否则没法定标准。见 [[概念与公式/氢耗测试方法]]。
2. **温度与辅助设备**：空调、暖风、电控、水泵——这些"不干正事"的电器也要耗电，电从氢气来，所以**大夏天开冷气、大冬天开暖风，氢耗都会涨**。有文献专门研究过：热管理系统能占到整车能耗的相当比例。

## 五、把"决定因素"串成一张图

```
        车要克服的阻力                   能量转换的效率                   电力的分配
  ┌─────────────────────┐   ┌──────────────────────────┐   ┌──────────────────┐
  │ 滚动阻力（车重、轮胎） │   │ 燃料电池发电效率（出力点） │   │ 能量管理策略 EMS   │
  │ 空气阻力（速度²）     │ → │ 电机效率                │ → │ （燃料电池vs电池） │
  │ 坡度阻力（坡度）      │   │ 传动效率                │   │ 再生制动回收      │
  │ 加速阻力（加速度）    │   │ 电池充放电效率           │   │ 辅助设备功耗      │
  └─────────────────────┘   └──────────────────────────┘   └──────────────────┘
               ↑                                                      ↑
       由"车速、加速度、坡度"决定                            由"控制策略"决定
               │                                                      │
               └────────────── 全都折算成 → 氢气消耗量（kg/100km） ────┘
```

## 六、结论（先记住这三句）

1. **氢耗 = 克服阻力的能量 ÷ 能量转换效率**，阻力由"车速、加速度、坡度、车重"决定。
2. **燃料电池有一个"高效出力区"**，让它在那个区间干活最省氢气，这是所有优化的共同出发点。
3. **能量管理策略决定燃料电池和电池谁出力**，是降氢耗的最大杠杆（文献里能省 10%~58%）。
