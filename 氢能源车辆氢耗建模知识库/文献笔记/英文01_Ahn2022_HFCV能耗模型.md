## 内容简介（人话版）

交通工程师想要"评估一条路、一个交通方案能省多少氢"，需要一套**只要输入车速、加速度、坡度就能算氢耗**的简单公式。这篇论文就用 2017 款丰田 Mirai 的数据，造出了这样一套微观能耗模型。

核心成果：
1. 用 4 条公式把整车功率需求算出来（阻力公式 + 燃料电池/电池分工公式）；
2. 标定出这辆车的几个关键参数（阈值功率、分界车速等）；
3. 在 UDDS、Highway、NEDC 三个标准工况下验证：**燃料电池能耗误差综合仅 0.86%，总能耗误差 2.17%**；
4. 用独立的 WLTP 数据再验证：**误差 1.9% 和 1.0%**——说明模型可移植、可信赖。

## 原理介绍（技术角度）

**式(1) 车轮需求功率**（详细拆解见 [[概念与公式/行驶阻力与车轮功率]]）：
$$P_{wheels}=\max\Big\{0,\;\big[ma+\tfrac{mgC_r}{1000}(c_1v+c_2)+\tfrac{1}{2\cdot3.6^2}\rho A_f C_D v^2+mg\theta\big]\tfrac{v}{3.6}\Big\}$$

**式(2)(3) 电池与燃料电池分工**（按功率、车速分 4 种模式）：

| 条件 | 电池出力 | 燃料电池出力 |
|---|---|---|
| $P_{wheels}\le P_a$（轻载） | 全包（$P_{wheels}+P_{aux}$） | 待机 $P_{idle}$ |
| $P_a<P_{wheels}\le P_b$ 且低速 | 全包 | 待机 $P_{idle}$ |
| $P_a<P_{wheels}\le P_b$ 且高速 | 待机 $P_{idle}$ | $P_{wheels}\cdot\beta$ |
| $P_{wheels}\ge P_b$（重载） | $P_{wheels}\cdot\alpha$ | $P_{wheels}\cdot\beta$ |

**式(4)(5) 总功率与能耗**：$P_{HFCV}=P_{battery}+P_{fuelCell}$，$EC=P_{HFCV}\cdot\Delta t$。

**标定参数**（2017 Toyota Mirai）：

| 参数 | 值 | 含义 |
|---|---|---|
| $m$ | 1928 kg | 整备质量 |
| $A_f$ / $C_D$ | 2.3316 m² / 0.28 | 迎风面积 / 风阻系数 |
| $v_a$ / $P_a$ / $P_b$ | 32 km/h / 2.5 kW / 5 kW | 分界车速 / 阈值功率 |
| $\beta$ | 93% | 传动+电机效率 |
| $\alpha$ | 20% | 电池出力折算效率（实测标定） |
| 氢能量密度 | 33.6 kWh/kg | 每公斤氢的可用电能 |
| 储氢量 | 5 kg | Mirai 的氢气罐 |

## 🧓 老奶奶讲故事

奶奶，想象丰田 Mirai 是一头"吃氢气、拉电"的机器驴，咱们要给它写一份**使用说明**，让人一看"这头驴现在跑多快、上不上坡"，就能算出"它一会儿要吃掉多少斤草（氢气）"。

阿恩博士研究出来的使用说明就 4 句话（4 条公式）：
1. 先算"驴拉车要费多大力"：跑得快（风阻）、拉得重（滚阻）、上坡、加速，一项项加起来（式1）；
2. 再定"驴和充电宝谁出力"：轻活让充电宝顶，快跑让驴干主力，猛劲时俩一起上（式2、3）；
3. 把俩的力气加起来（式4）；
4. 力气 × 时间 = 用了多少电，再折算成草料斤数（式5）。

然后他拿着这份说明去"验证"：让真驴跑三条标准路线（市区、高速、综合），说明书算出来的草料量，和实际吃的**误差不到 3%**——就跟算盘打的数跟电子秤称的数差不离。

奶奶你看——**好的公式，就是"看一眼路况就能报出油耗"的老把式经验，只不过用数学写了下来**。

## 关键数据（验证结果）

| 工况 | 燃料电池能耗误差 | 总能耗误差 |
|---|---|---|
| UDDS（市区） | 13.83% | −3.21% |
| Highway（高速） | 0.61% | 9.36% |
| NEDC（综合） | −3.45% | −3.64% |
| **综合** | **0.86%** | **2.17%** |
| 独立数据 WLTP 验证 | 1.9% | 1.0% |

> 说明：模型更擅长高速/激进工况（标定时如此），低速市区工况误差偏大；作者自认局限——电池模式其实还依赖电池 SOC，而测试数据没含 SOC。

## 与"氢耗建模"课题的关系

**这是本库最核心的"氢耗决定因素 + 公式"文献**：
- 明确回答了"氢耗由什么决定"：车速、加速度、坡度、车重、空气阻力系数、燃料电池/电池分工模式、辅助功耗；
- 给出了可直接套用的完整公式链（式1~5）；
- 验证了"微观模型"的精度量级（<3%）——这是"氢耗建模"能达到的精度基线。
- 后续很多论文（Duan、Jiang、Blades 等）都以它为建模参考。
