## 内容简介（人话版）

氢能公交车上有两个"供能口"：燃料电池（烧氢气发电）和动力电池（存电）。**什么时候让燃料电池干活、什么时候让电池顶上、刹车要不要"捡"能量回来**——这套"管事规矩"叫能量管理策略（EMS）。

作者在 MATLAB/Simulink 里搭了一辆燃料电池客车的"前向仿真模型"（车跟着司机指令真实跑起来），然后用 Stateflow 写了 4 套不同的"管事规矩"（2 种功率跟随 + 2 种开关控制），让车跑中国客车标准工况 **CHTC-C**，看哪套最省氢。

**结果**：4 套规矩都能让车正常跑完工况，其中"**开关控制**"的规矩三最省——**百公里等效氢耗 6.447 kg**。

## 原理介绍（技术角度）

**① 整车前向仿真框架**（真实工业做法）：

```
工况 → 驾驶员模型(PID) → 需求功率 → 能量管理策略(Stateflow)
      → 燃料电池模型 + 电池模型 → 电机模型 → 纵向动力学 → 车速(反馈给驾驶员)
```

**② 燃料电池半经验模型**：单体电压 = 开路电压 − 活化过电压 − 欧姆过电压（还提到浓度过电压），与 [[文献笔记/中文02_朱丹2024_大功率氢燃料电池动力系统节能优化]] 的电化学模型同源。

**③ 纵向动力学**（四种阻力，与 [[概念与公式/行驶阻力与车轮功率]] 一致）：
$$F_\omega = \underbrace{\frac{cAv^2}{21.15}}_{空气} + \underbrace{mgf\cos\theta}_{滚动} + \underbrace{mg\sin\theta}_{坡道} + \underbrace{\delta m\frac{dv}{dt}}_{加速}$$

**④ 4 种策略的核心区别**（本质是两问两答）：
| | 谁优先出力？ | 燃料电池能给电池充电吗？ |
|---|---|---|
| 规则一（功率跟随） | 燃料电池优先 | 不给 |
| 规则二（功率跟随） | 燃料电池优先 | 可以（SOC<80%时） |
| 规则三（开关控制） | SOC≥80% 电池优先，否则燃料电池优先 | 不给 |
| 规则四（开关控制） | SOC≥80% 电池优先，否则燃料电池优先 | 可以 |

- "开关控制"很像"看冰箱剩多少菜再决定做不做饭"：电池电多就先用电，少了再开燃料电池；
- 结果规则三最省，说明**"电池高电量时让它先出力 + 不给燃料电池充电"这套组合在客车上最经济**。

## 🧓 老奶奶讲故事

奶奶，把这辆氢能公交车想成你家楼下的小卖部，有**两个伙计**：
- 燃料电池——像**发电的老板**，自己买氢气发电，力气大但"起锅"慢、费料；
- 动力电池——像**存电的充电宝**，平时把电攒着，关键时刻秒出电，但电用完了要充电。

"能量管理策略"就是**店里的排班表**，规定什么时候让谁干活。

袁师傅一口气写了 4 张排班表：
1. 老板一直干，充电宝只在猛劲时搭把手（可老板不充电宝充电）；
2. 同上，但老板忙完了会给充电宝充电；
3. 充电宝电多就先让充电宝顶着，电少了才让老板上，老板不给充电宝充电（**这张最省！**）；
4. 同 3，但老板会给充电宝充电。

结果发现：**第三张表最省钱**——充电宝有电就先用它（省氢气），而且老板干完活别急着充电宝充电（那电也是用氢气发的，绕一圈又费一遍）。

奶奶你记住：**"谁省钱先用谁"有时候比"想尽办法充电"更省钱**，这就是能量管理的基本智慧。

## 与"氢耗建模"课题的关系

- 提供了一个**完整的氢耗仿真建模流程模板**（工况→驾驶员→EMS→燃料电池/电池→电机→动力学闭环），做氢耗建模可直接复用；
- 直接对比了不同能量管理策略的氢耗差异，是"**策略如何影响氢耗**"的实证案例；
- 氢耗 6.447 kg/100km 的量级（客车）与轿车（<1 kg）差异巨大，佐证"车型决定氢耗量级"。
